# Local LLM Wiki v10.1

差し替えるファイルは2つだけです。

- `scripts/enrich.py`
- `docs/assets/wiki-v10.js`

追加機能:
- 推奨量子化（バランス / 品質 / 省メモリ）
- 必要RAM / VRAMの概算
- 対応ランタイム判定
- 用途評価

注意:
- メモリ値はファイル容量ベースの概算です。
- ランタイム互換は「明示あり」と「互換候補」を区別します。
- 用途評価の「情報不足」は不得意という意味ではありません。
- AdSenseコードや `docs/index.html` は変更しません。

反映後:
Actions → Daily Local LLM Research → Run workflow
を1回手動実行してください。
