お問い合わせ

Local LLM Wiki に関するお問い合わせは、下記の窓口をご利用ください。

お問い合わせ窓口

Local LLM Wiki - GitHub Issues

記事内容の誤り、リンク切れ、権利関係、広告、サイト表示の不具合、その他のご連絡を受け付けています。

お問い合わせ時のお願い

可能であれば、対象ページのURLと内容を具体的に記載してください。記事の訂正依頼の場合は、根拠となる公式情報や一次情報のURLも添えていただけると確認がスムーズです。

個人情報について
GitHub Issues は公開される場合があります。氏名、住所、電話番号、メールアドレス、アカウント情報など、公開したくない個人情報は投稿しないでください。

対応について

内容を確認のうえ、必要に応じて記事の修正やサイト改善を行います。すべてのお問い合わせへの個別返信や対応を保証するものではありません。
